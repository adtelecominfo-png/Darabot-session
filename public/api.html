Developer documentation

Pair WhatsApp devices
from your bot.

Generate an 8-character WhatsApp Pair Code through a simple JSON API, then poll for the completed SESSION_ID and raw creds.json data.

Quick startView endpoints

Quick start

Send a phone number with its country code. Do not include spaces or the plus sign. The user enters the returned code in WhatsApp under Linked Devices → Link with phone number instead.

POST/api/pair
curl -X POST /api/pair \
  -H "Content-Type: application/json" \
  -d '{"phoneNumber":"2348152077346"}'

1. Receive the code

The API immediately returns the Pair Code and a temporary session key.

{
  "ok": true,
  "code": "AB12CD34",
  "pairingCode": "AB12CD34",
  "sessionKey": "examplekey",
  "pollUrl": "/api/pair/poll/examplekey",
  "expiresIn": 600
}

2. Poll completion

Poll the returned URL every few seconds until done becomes true.

curl /api/pair/poll/examplekey

Completed response

When WhatsApp pairing finishes, use encoded as your SESSION_ID. The decoded value is the raw creds.json file content.

{
  "done": true,
  "encoded": "BASE64_SESSION_ID",
  "decoded": "{\\"creds\\":{...}}",
  "error": null
}
Keep both values private. They can grant access to the connected WhatsApp account. The API is rate-limited per IP and follows the site's maintenance mode.

Endpoint reference

EndpointPurposeInput
POST /api/pairCreate a new pairing session.JSON: phoneNumber
GET /api/pair?number=...GET alternative for simple integrations.Query: number
GET /api/pair/poll/:sessionKeyCheck whether pairing is complete.Path: sessionKey

Errors

  • 400 — invalid or missing phone number
  • 429 — too many requests; retry later
  • 503 — website is in maintenance mode
  • 500 — pairing service could not start

Code format

The returned code and pairingCode are the same eight-character value, normalized without spaces for easy bot handling.
